# 잠실야구장 좌석 맵 가이드

> 이 문서는 NOL 티켓의 잠실야구장 좌석 선택 화면을 분석한 결과를 기록합니다.
> 실제 개발 시 브라우저 DevTools로 직접 확인 후 업데이트하세요.

## 구역 우선순위

| 순위 | 구역번호 | 구역명 | 비고 |
|------|---------|--------|------|
| 1 | **112, 113** | 중앙 테이블석 | 3인/4인 테이블 단위, **3석** 예매 목표 |
| 2 | **318, 319** | 중앙 네이비석 | 1순위 매진 시 |
| 3 | KIA 응원석 | 3루 방향 | 2순위 매진 시 순차 시도 |

## 좌석 맵 확인 방법 (개발자용)

### 1. 브라우저 DevTools로 선택자 확인

1. 잠실야구장 KIA 경기 티켓 상품 페이지 접속
2. F12 (DevTools) → Elements 탭
3. 좌석 맵 영역에서 각 구역 요소의 `class`, `id`, `data-*` 속성 확인
4. 아래 `## 확인된 선택자` 섹션 업데이트

### 2. 좌석 맵 타입 파악

| 타입 | 확인 방법 | seat_selector.py 대응 |
|------|----------|----------------------|
| HTML/SVG | Elements에서 `<path>`, `<rect>` 등 | CSS 선택자로 클릭 |
| Canvas | Elements에서 `<canvas>` 요소 | 좌표 클릭 방식 |

### 3. Network 탭에서 API 확인

- 좌석 선택 시 발생하는 XHR/Fetch 요청 기록
- `poller.py`의 `API_URL_TEMPLATE` 업데이트에 활용

> 좌석 맵이 `<canvas>` 기반인 경우, 구역별 클릭 좌표를 아래에 기록하세요.

## 좌석 타입 특이사항

- **112/113 테이블석**: 4인 테이블과 3인 테이블이 혼합
  - 3장 예매 시: 3인 테이블 우선 → 없으면 4인 테이블에서 3석
  - 테이블 단위 선택인지, 개별 좌석 선택인지 확인 필요
- **318/319 네이비석**: 일반 개별 좌석 방식 (추정)
